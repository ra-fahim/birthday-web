# Canvas Editor Update

- Removed the old Studio/dashboard editing UI from the editor flow.
- The website editor is now canvas-first: the selected template is the editing surface.
- Canvas editing is enabled by default when an existing website is opened.
- Clicking an editable element opens the contextual inspector below the canvas.
- Previous / Next screen controls stay visible while canvas editing is enabled.
- Removed visible Studio terminology from the app, dashboard, feature/help copy and template runtime comments.
- The account workspace still lists saved websites, but editing always happens from the selected template canvas.
- Legacy sidebar/form code remains only as dormant source compatibility and is no longer rendered.

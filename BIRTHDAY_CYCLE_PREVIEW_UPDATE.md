# Birthday Cycle + Preview Behavior Update

- Demo mode remains fully isolated from account/site content and always uses the Master Birthday template defaults.
- Editor Preview always runs a simulated 10-second final countdown, regardless of the selected birthday being far in the future or already past.
- Published/live birthday pages now use an exact 24-hour Greeting window starting at the configured birthday date/time.
- After that 24-hour Greeting window ends, the live page starts a countdown to the same month/day/time in the next year.
- The live cycle keeps advancing yearly without affecting Demo defaults or editor preview behavior.

# Canvas Countdown + Secret Link Fix

- Fixed Master Template canvas editor countdown overlay: editor-mode countdown refreshes only the displayed numbers/message and never changes screen visibility.
- Previous/Next screen navigation remains the sole owner of editor screen transitions.
- Added a visible editor-only `Edit profile link ↗` control on the Secret screen.
- Clicking the Secret profile-link control selects `mb.secret.socialUrl`, supported by the Universal Element Editor.
- The profile URL editor accepts Instagram, Facebook, website, or any public profile URL.
- The editor-only link control stays hidden in visitor/demo mode.

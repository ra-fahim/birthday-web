# 💝 For My Valentine (Sherry)

A personalized, interactive digital experience built with love for Sherry. This application is a collection of memories, future plans, and comforting words, all wrapped in a beautiful, responsive web interface.

## ✨ Features

### 🎵 Background Music
- **One Single Track:** The site owner uploads exactly one audio file in Wishly Studio (Music tab).
- **Intro-Aware:** Playback starts only after the intro gate is completed, so browsers never block it.
- **Quiet Control:** A small mute / unmute button sits in the bottom-left corner.
- **Optional:** No file uploaded means no audio element at all.

### 📅 Date Planner
- **Interactive Tickets:** Choose from a curated list of date ideas (e.g., "Capital Town", "Arcade & Ice Cream").
- **Email Integration:** Generates a professional, aesthetic email ticket with details like time, budget, and a special message.
- **Modern Ticket Design:** Features a clean, receipt-style layout that works perfectly with Gmail.
- **One-Click Sending:** Opens the ticket directly in your default email client.

### 🍞 Toast Notifications
- **Enterprise-Grade Design:** Custom-built notification system with success, info, and error states.
- **Responsive & Centered:** Perfectly positioned at the top-center of the screen, ensuring visibility on any device.
- **Always on Top:** Uses React Portals to render above all other UI elements (z-index 99999).
- **Auto-Dismiss:** Notifications gently fade away after a few seconds.

### 💌 Other Sections
- **Intro Gate:** A welcoming sequence to set the mood.
- **Love Notes:** A collection of heartfelt messages.
- **Comfort Corner:** A safe space with reassuring words for tough days.
- **Bloom Garden:** A digital garden of memories.
- **Museum Gallery:** A photo gallery of our best moments.
- **Bucket List:** Shared dreams and goals.
- **Final Letter:** A closing message to seal the experience.

## 🛠️ Technology Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS (with custom "Love" theme variables)
- **Animations:** Framer Motion (for smooth transitions and interactive elements)
- **Icons:** Lucide React
- **Language:** TypeScript

## 🚀 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/my-valentine.git
    cd my-valentine
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Open in your browser:**
    Navigate to `http://localhost:5173` (or the port shown in your terminal).

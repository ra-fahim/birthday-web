# Canvas Edit Highlight + Cake Group Update

- Stronger always-on editable highlights in Master Birthday edit mode.
- Cake first line, second line, and recipient name now share one selection key (`mb.cake.group`).
- Clicking any cake text opens one editor card containing all three editable fields.
- Changes remain live in the canvas.
- Synthetic cake-group selections are ignored by the generic text-save handler so they cannot create invalid config paths.
